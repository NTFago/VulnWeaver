# ADR-012：本地内容寻址工件存储

- 日期：2026-09-07
- 状态：已接受
- 影响模块：M02、M04、M09-M16

## 上下文

首版需要在不信任上传文件名和宿主路径的前提下保存原始样本与派生产物，并允许生产环境替换为 MinIO。工件内容和 PostgreSQL 元数据的职责必须分离，且相同内容不得产生可覆盖的第二份对象。

## 决策

- 定义与具体后端无关的 `ArtifactStore` 接口，首版实现服务自主管理目录下的本地后端。
- 对输入流增量计算 SHA-256，以 `cas://sha256/<hex>` 作为唯一对象引用，并使用两级摘要目录避免单目录膨胀。
- 内容先写入同文件系统的 staging 文件，完成大小检查、刷盘和摘要计算后，以排他硬链接原子发布；目标已存在时校验内容并复用，绝不覆盖。
- 存储接口只接受内容流和对象引用，不接受调用方提供的目标路径，也不提供原地修改或删除接口。
- PostgreSQL 保存 Artifact、ArtifactVersion、摘要、父版本、工具身份与生成配置；对象写入先于元数据事务，事务失败产生的未引用对象允许由后续受控 GC 处理，不主动删除可能已被其他记录复用的内容。

## 后果

- 同一内容稳定得到相同摘要和对象引用，并可跨 Artifact 复用物理对象。
- 派生工件必须提供父版本与工具身份，所有已登记版本保持只追加。
- 本地存储根目录必须仅由服务账户写入；未来 MinIO 实现必须维持相同的不可变、校验与引用语义。
