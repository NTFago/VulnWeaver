# ADR-009：容器化开发环境

- 日期：2026-09-07
- 状态：已接受
- 影响模块：本地开发、基础设施、CI 和最终镜像交付

## 上下文

系统最终以多个 Docker 服务镜像和 Compose 部署清单交付，需要降低本机差异，同时保持控制面与不可信样本执行面的安全边界。

## 决策

- 使用 `.devcontainer/` 提供统一开发工具环境。
- 使用 `compose.yaml` 描述基础服务，使用 `compose.dev.yaml` 添加源码挂载、开发容器和本机调试端口。
- 开发容器不挂载 Docker Socket，不承担 Sandbox Runner 职责。
- 最终服务镜像使用独立、多阶段 Dockerfile；生产配置不得绑定挂载源码。

## 后果

开发容器可以编译、测试和调试控制面代码，但不能直接运行未知样本、Poc 或利用脚本。后续 Sandbox Runner 必须使用独立运行时连接和更严格的网络、文件系统及资源策略。
